### Connect 5 AI Solver

A high-performance, web-accessible Connect 5 game with a real-time AI solver.


**Requirements:** The application requirs Python **3.8+**, uses a lightweight browser-based interface built entirely with HTML / CSS / Vanilla JavaScript (No frontend build system is required)

**Running:** Run the application `python app.py` Then open `http://127.0.0.1:8000`
